# Where-to-Buy Platform Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Executed inline in this session.

**Goal:** Multi-brand platform with login, manual entry, CSV upload and a public catalog endpoint feeding the existing widget.
**Architecture:** See `docs/superpowers/specs/2026-11-16-platform-design.md`.
**Tech Stack:** Node 26 (`node:sqlite`, `node:crypto`), Hono, React + Vite, Vitest, Playwright.

## Global Constraints
Spec constraints from the platform and widget specs apply: http(s) URLs only; ids `^[A-Za-z0-9._-]{1,64}$`; all admin queries scoped by session brand; CSRF header + Origin check on mutations; scrypt password hashing; token hashes only in DB; public endpoint CORS `*` with ETag; widget bundle <= 15 kB gzip; widget `data-catalog` keeps precedence over `data-brand`.

## Tasks (each ends with passing tests and a commit)
1. **Widget `data-brand`**: `src/resolve.ts` `resolveDefaultCatalog(script: {src: string; dataset: Record<string,string|undefined>}): string | undefined`; wire into `src/where-to-buy.ts`; test `tests/resolve.test.ts`.
2. **DB + auth primitives**: `server/db.ts` `openDb(path): DatabaseSync` (schema, foreign keys on); `server/auth.ts` `hashPassword`, `verifyPassword`, `newToken`, `sha256`; test `tests/server/auth.test.ts`.
3. **Store + validators**: `server/validators.ts` (`validateProduct/Retailer/Offer` returning string[]); `server/store.ts` (`getCatalog`, `upsertProduct`, `deleteProduct`, `upsertRetailer`, `deleteRetailer`, `upsertOffer`, `deleteOffer`, `importCatalog`, all `(db, brandId, ...)`); test incl. cascade, rollback, isolation.
4. **App: auth + sessions + guards**: `server/app.ts` `createApp(db, opts?)` signup/login/logout/me, session middleware, CSRF/Origin checks, login rate limit; test `tests/server/auth-routes.test.ts`.
5. **App: admin CRUD, import/export, public catalog**: routes in `server/app.ts`; tests `tests/server/admin-routes.test.ts`, `public-routes.test.ts`.
6. **Server entry**: `server/index.ts` (env `PORT`, `DB_PATH`; serves `/wtb.js` and admin SPA).
7. **Admin SPA**: `admin/` React pages (Auth, Products, Retailers, Offers, Import, Embed); `npm run build:admin`.
8. **Platform E2E**: `playwright.platform.config.ts`, `e2e-platform/platform.spec.ts`.
9. **Docs**: README platform section.
